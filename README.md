# BikeSharingDemandPrediction
Bike Sharing Demand Prediction: hourly rental forecasts for Capital Bikeshare 2011–2012 from weather, season and time features. HistGradientBoosting (RMSLE 0.53) with tutorial-style Streamlit UI: guided predictions, batch CSV scoring, demand insights and model leaderboard. Internship project. Python, scikit-learn, XGBoost, Streamlit.
